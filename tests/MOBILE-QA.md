# Android 手机回归测试表（v0.3）

此表为需要在实际手机上执行的验收项；不是已经通过的实测记录。

## 文件操作

- [ ] 系统设置 → 文件与导入导出 → 测试导出：下载/SillyTavern/ST-Launcher-export-test.txt 已写入正确中文。
- [ ] 酒馆普通角色卡导出：保存 PNG 或 JSON，能再次导入并读到图片/内容。
- [ ] 酒馆预设导出：保存 JSON/ZIP，能重新导入同一预设。
- [ ] 酒馆聊天记录导出：保存 JSONL / TXT / JSON，保存后用文件管理器打开检查首尾内容。
- [ ] 第三方「酒馆助手」预设导出（截图报错位置）：不再报 Failed to fetch，文件真实存在；若失败记录提示和插件版本。
- [ ] 多文件导入：从系统文件选择器多选（仅网页允许多选时），确认酒馆成功识别文件。
- [ ] 角色卡/世界书文件导入：应用内不出现文件权限错误。
- [ ] 从 HTTP(S) 下载附件：系统下载通知显示完成且下载目录有真实文件。
- [ ] 删除聊天：按酒馆确认弹窗删除后，重开仍已删除。
- [ ] 删除或取消删除预设：酒馆正常响应，启动器不绕过确认。
- [ ] 手动清缓存后：登录状态、角色与服务器聊天数据仍正常；下载的文件仍存在。

## 显示和后台

- [ ] 挖孔屏竖屏全屏：顶栏按钮可点，不被摄像头遮挡。
- [ ] 挖孔屏横屏全屏（如适用）：两侧按钮可点，不被挖孔遮挡。
- [ ] 进入设置再返回：聊天页面和消息历史未重载。
- [ ] 切到后台 30 秒仍回到同一会话；提示音/震动按开关生效。
- [ ] 关闭屏幕，使用常用剧情生成功能后恢复，记录实际是否被系统冻结；不可将前台服务视作保证。
- [ ] 通知栏「软件设置 / 注销绑定」均能执行，注销需二次确认。
- [ ] HTTP 酒馆网址不会被启动器改成 HTTPS。
